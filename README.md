# pairwise-enum-guard

登录和找回密码接口一开放，账号枚举就能从响应差异里读出来：不存在用户返回 404，存在返回 401；提示语区分“用户不存在”和“密码错误”；找回密码对不存在邮箱也发信，但响应时间明显更短；锁定策略只对存在的账号生效；邮箱大小写和别名没有归一；第三方登录回调泄露账号状态；注册接口能查重；验证码只在存在账号时要求；错误码细分到具体原因；响应长度随用户存在与否变化。security/enum_guard.py 是核心，tests/test_enum_guard.py 15个红。要修的是：统一状态码；统一提示语；响应时间填充；锁定覆盖不存在账号；邮箱归一；回调统一；注册查重脱敏；验证码统一；错误码粗化；响应长度固定。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：漏洞检测与攻防；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
